# 역직구 열 대응표 (우리 평면 표 → 각 마켓 일괄등록 양식)

> 각 마켓 공식 양식(아마존 flat-file 카테고리 템플릿 · 라쿠텐 RMS CSV · 큐텐 QSM 엑셀 · 쇼피 Mass Upload)은 각 판매자센터에서 내려받아야 합니다.
> `global.html` ④ 탭 파일은 **붙여넣기용 근사 열**입니다. 확인 2026-11-20(로그인 화면이라 원문 대조 미실시).

## 아마존 (14열) `아마존_등록_*.xlsx`
| 우리 열 | flat-file 필드 | 값 |
|---|---|---|
| sku | item_sku / sku | `KTS-G-…-US` |
| item_name | item_name | 미국 제목(≤200자) |
| brand_name | brand_name | `Generic` (브랜드 임의 사용 0) |
| price | standard_price | ② 마진표 권장가(USD) |
| quantity | quantity | 50 |
| product_description | product_description | 설명 3문단 |
| bullet_point1~5 | bullet_point1~5 | 불릿 5 (각 ≤200자) |
| main_image_url | main_image_url | 이미지 호스팅 주소로 교체 |
| country_of_origin | country_of_origin | 원산지 한국이면 `South Korea`, 아니면 입력값 |
| item_weight | item_weight + unit | `120 g` |
검색어(generic_keywords)는 ① 탭 "검색어(백엔드)"를 따로 붙여넣습니다(≤250바이트).

## 라쿠텐 / 큐텐 (7열) `라쿠텐큐텐_등록_*.xlsx`
| 우리 열 | 라쿠텐 RMS / 큐텐 QSM | 값 |
|---|---|---|
| 상품번호 | 商品管理番号 / 판매자상품코드 | `…-JP` |
| 상품명 | 商品名 | 일본 제목(60자 권장) |
| 판매가 | 販売価格 | 권장가(JPY) |
| 재고 | 在庫数 | 50 |
| 상품설명 | 商品説明文 | 상품설명 |
| 이미지URL | 商品画像URL | 호스팅 주소 |
| 배송비 | 送料 | 0 (운임은 인보이스에 상품가와 **따로** 적기 — 일본 면세 판정) |

## 쇼피 (8열) `쇼피_등록_*.xlsx`
| 우리 열 | Mass Upload 필드 | 값 |
|---|---|---|
| SKU | Parent SKU | `…-SEA` |
| 상품명 | Product Name | 쇼피 제목(≤120자) |
| 가격 | Price | 권장가(현지통화) |
| 재고 | Stock | 50 |
| 설명 | Product Description | 설명 3문단 + 해시태그 8 |
| 이미지 | Cover image | 호스팅 주소 |
| 중량 | Weight (kg) | g ÷ 1000 |
| 차원 | Length/Width/Height | 크기 입력값 |
