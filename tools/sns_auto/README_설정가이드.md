# 쓰레드·블로그 자동 올리기 — 처음 설정 10분

이 문서만 따라 하면 내일 아침부터 자동으로 올라갑니다.
준비물: ① 쓰레드(인스타) 계정 ② 네이버 블로그 ③ 이 PC의 크롬.
(파이썬 3.12는 이 PC에 이미 깔려 있습니다. 모든 파일은 이 폴더 `tools\sns_auto\` 안에 있습니다.)

---

## 1단계. 쓰레드 토큰 받기 (5분 · 한 번만)

1. 인터넷 창에서 `developers.facebook.com` 을 엽니다. 페이스북 계정으로 로그인합니다.
2. 오른쪽 위 **내 앱** → **앱 만들기**를 누릅니다.
3. 앱 이름을 아무거나 적습니다(예: `KTS 글자동`). 사용 사례를 고르라고 하면 **Threads API**가 있는 항목을 고릅니다. 없으면 **기타**로 만들고 다음 화면에서 추가합니다.
4. 앱 화면 왼쪽에서 **제품 추가** → **Threads API** 를 찾아 **설정**을 누릅니다.
5. **역할(Roles) → Threads 테스터 추가**에서 **내 쓰레드 사용자 이름**을 넣고 추가합니다.
6. 폰의 **쓰레드 앱 → 설정 → 계정 → 웹사이트 권한 → 초대**에 들어가 **수락**을 누릅니다. (이 단계를 빠뜨리면 9번에서 막힙니다.)
7. 앱 화면의 **앱 설정 → 기본**에서 두 가지를 메모합니다.
   - **앱 ID** (숫자)
   - **앱 시크릿** (영문·숫자 섞인 긴 문자열, `보기`를 눌러야 보입니다)
8. 같은 화면의 **Threads API 설정**에서 **리디렉션 URI** 칸에 아래를 넣고 저장합니다.
   `https://localhost/`
9. 아래 주소를 브라우저에 붙여 넣고, 권한 화면에서 **허용**을 누릅니다. (앱 ID 부분만 7번 값으로 바꿉니다)
   `https://threads.net/oauth/authorize?client_id=내앱ID&redirect_uri=https://localhost/&scope=threads_basic,threads_content_publish,threads_manage_replies&response_type=code`
10. 허용하면 주소창이 `https://localhost/?code=AQ...` 처럼 바뀝니다(화면은 하얗게 나옵니다 — 정상입니다).
    **주소창의 `code=` 뒤부터 `#` 앞까지**를 통째로 복사합니다. (주소 전체를 복사해도 됩니다 — 알아서 code만 뽑습니다.)
11. 이 폴더에서 `threads_token.bat` 을 실행하고 `1`을 고른 뒤, 물어보면 **앱 ID → 앱 시크릿 → 복사한 code** 순서로 붙여 넣습니다.
    (앱 시크릿은 붙여 넣어도 화면에 안 보입니다 — 정상입니다. 시크릿은 어디에도 저장하지 않습니다.)
    마지막에 `[OK] .env.local 저장 완료` 가 나오면 끝입니다.
    - `code`는 **한 번만** 쓸 수 있고 **10분** 안에 써야 합니다. 실패하면 9번부터 다시 하세요.
    - 토큰은 **60일**짜리입니다. 45일이 지나면 자동으로 갱신됩니다. `threads_token.bat` 을 다시 실행해 `2`(갱신)를 골라도 됩니다.

---

## 2단계. 네이버 블로그 연결 (3분 · 한 번만)

1. `start_sns_chrome.bat` 을 두 번 누릅니다. **전용 크롬 창**이 하나 열립니다(평소 쓰는 크롬과 따로입니다).
2. 그 창에서 `blog.naver.com` 으로 들어가 **네이버에 로그인**합니다.
   - 아이디·비밀번호는 **어디에도 저장하지 않습니다.** 이 창에만 남습니다.
   - `로그인 상태 유지`가 있으면 체크해 두세요.
3. 내 블로그 주소를 확인합니다. 주소가 `blog.naver.com/abcd1234` 이면 **`abcd1234`** 가 블로그 아이디입니다.
4. 이 폴더의 `.env.local` 을 메모장으로 열어 아래 한 줄을 채웁니다. (1단계를 했으면 파일이 이미 있습니다. 없으면 새로 만드세요.)
   `NAVER_BLOG_ID=abcd1234`
5. **이 크롬 창은 닫지 마세요.** 닫으면 자동 임시저장이 안 됩니다. (PC를 끄면 다시 켜고 이 파일을 한 번 실행하면 됩니다.)

---

## 2-1단계. 사진 준비 (글마다 2~3장 · 5분)

블로그 글은 **사진이 2장 이상 있어야 저장됩니다**(글만 있는 포스트는 내보내지 않습니다). 사진 파일은 `images\` 폴더에만 두고 저장소에는 올리지 않습니다.

1. 전용 크롬(`start_sns_chrome.bat`)이 켜져 있는지 확인합니다.
2. `py -3 prepare_images.py --audit` — 글마다 사진이 몇 장 있는지 표로 봅니다.
3. `py -3 prepare_images.py --prepare` — 없는 사진만 채웁니다(사이트 화면을 1200×800으로 찍음). 다시 다 찍으려면 `--prepare --force`.
   - 화면에 **실제 전화번호**가 보이는 컷은 자동으로 버립니다(하단 `문의` 줄은 그 탭에서만 숨기고 찍음, 예시 번호 `010-1234-5678` 은 통과).
   - 경사도처럼 무료 횟수가 있는 도구는 **조회를 일으키지 않는 화면**만 찍습니다.
   - 검사 기준: PNG · 가로 800 이상 · 세로 500 이상 · 40KB 이상 · 같은 사진 중복은 1장으로 셈.
4. 2장 미만인 글은 큐에 `photo_missing` 표시가 붙고, 임시저장에서 **건너뜁니다**.

---

## 3단계. 글 10편 미리 채우기 (1번만 · 10~15분)

1. `fill_naver_10.bat` 을 두 번 누릅니다(또는 아래 명령).
   `py -3 naver_blog_draft.py --live --count 10`
2. 크롬 창이 스스로 움직이며 블로그 **임시저장함**에 글을 하나씩 넣습니다. **발행은 하지 않습니다.**
3. 끝나면 마지막 줄에 `임시저장 10건 완료` 가 찍힙니다.
4. 네이버 블로그 → **글쓰기 → 임시저장** 목록에서 10편을 확인합니다.
   - 글은 **잡지처럼 조판**되어 들어갑니다: 큰 소제목(■ 줄) · 인용구 박스 2개 · 구분선 · 사진 2~3장 · 문단 사이 여백.
   - 태그: 본문 맨 끝에 **빈 줄 2개 → 구분선 → `#태그` 12개 한 줄**로 따로 넣습니다(링크 줄과 붙지 않음). 네이버 태그 칸은 `발행` 설정창 안에 있어 기계가 열지 않습니다.
   - 문구는 큐 원고 그대로입니다(서식만 입힘).

### 이미 들어간 임시저장 글을 새 양식으로 바꾸기(재작성)

1. `py -3 naver_blog_draft.py --list-drafts` — 임시저장함 실측(제목·번호·시각)과 큐 대조 3분류.
2. `py -3 naver_blog_draft.py --reconcile` — 위 결과를 큐에 적고 `post_queue.json` 을 커밋(다시 돌려도 2배로 늘지 않게).
3. `py -3 naver_blog_draft.py --rework --count 1` — **1편만** 같은 글 위에 덮어쓰기(새 글이 생기지 않음). 스크린샷 `logs/rework_*.png`, 실측 `logs/format_verify_날짜.json`.
4. 1편이 합격이면 `py -3 naver_blog_draft.py --rework --count 9`. 한 편이라도 기준 미달이면 거기서 멈춥니다.
   - 저장 뒤 임시저장 **개수가 늘면 즉시 전부 중단**합니다(중복 생성 방지). 옛 글 삭제는 하지 않습니다.
   - 검사만: `--audit`(브라우저 없이) · `--dry-run --key slope`(블록 계획 출력).

> 처음 한 번만 하면 됩니다. 이후로는 **하루 1편씩 새 글이 자동으로 채워집니다**(대표님이 1편 발행하면 다음 날 1편이 새로 채워지는 구조).

## 3-1단계. 쓰레드를 토큰 없이(전용 크롬으로) 올리기

페이스북 개발자 토큰을 못 받아도 됩니다. **전용 크롬에 쓰레드 로그인만 되어 있으면** 그 창으로 하루 1건 올립니다.

1. `start_sns_chrome.bat` 창에서 `threads.com` 에 들어가 **로그인**합니다(인스타 계정으로 계속하기). 왼쪽 아래에 `로그인` 버튼이 안 보이면 로그인된 상태입니다.
2. `.env.local` 에 아무것도 안 넣어도 됩니다(기본 `THREADS_MODE=auto` → 토큰이 없으면 크롬). 강제로 크롬만 쓰려면 `THREADS_MODE=chrome`.
3. 확인: `py -3 threads_autopost.py --dry-run --chrome` (네트워크 0건) → 실제: `py -3 threads_autopost.py --live --chrome`.
4. **전용 크롬 프로필(`%USERPROFILE%\KTS_SNS_CHROME`)은 지우지 마세요** — 네이버·쓰레드 로그인이 같이 사라집니다. 로그인이 풀리면 그 창에서 다시 로그인만 하면 됩니다(기계는 로그인을 시도하지 않습니다).
5. 링크 위치 스위치(한 줄): `THREADS_LINK_MODE=first_comment`(기본 — 본인 첫 댓글에 링크) / `THREADS_LINK_MODE=reply_on_request`(첫 댓글에도 링크 없음, 요청한 분에게만 수동 `--reply`). 본문에는 어느 쪽이든 링크가 들어가지 않습니다.
6. **댓글 단 분들께 자동으로 답글을 다는 기능은 없습니다.** 필요할 때만 대표님이 직접: `py -3 threads_autopost.py --reply <글 주소> "<문장>"`.

## 4단계. 자동 시작 걸기 (30초)

1. `register_sns_schedule.bat` 을 두 번 누릅니다.
   - 1·2단계가 안 끝났으면 `[등록 안 함]` 과 이유가 나옵니다. 그 항목을 마치고 다시 누르세요.
2. `[OK] … 다음 실행` 날짜가 보이면 성공입니다.
   - 쓰레드: **매일 08:10**
   - 네이버 임시저장: **매일 08:20**
3. PC가 꺼져 있어 못 돌린 날은 **PC를 켜면 곧바로 한 번** 돌아갑니다.
4. 시간을 바꾸고 싶으면:
   `schtasks /Change /TN "KTS_SNS_THREADS" /ST 19:30`

---

## 매일 하실 일 (3분)

1. 아침에 폰으로 **네이버 블로그 앱 → 임시저장**을 엽니다.
2. 맨 위 글을 읽고, 필요하면 문장 하나만 고칩니다.
3. **발행**을 누릅니다. (자동입력 방지 문자가 뜨면 그 자리에서 입력하시면 됩니다.)
4. 쓰레드는 **이미 올라가 있습니다.** 댓글에 링크가 달렸는지 한 번만 봐 주세요.

이게 전부입니다. 글 소재와 원고는 미리 10편이 쌓여 있고, 떨어지면 다시 채우면 됩니다.

## 잘 안 될 때

| 화면에 이렇게 나오면 | 뜻 | 이렇게 하세요 |
|---|---|---|
| `[SKIP] 토큰/사용자ID 없음` | `THREADS_MODE=api` 인데 토큰이 없음 | `threads_token.bat` 또는 `THREADS_MODE=auto`(크롬) |
| `[SKIP] 크롬 창이 없습니다` | 전용 크롬이 꺼졌습니다 | `start_sns_chrome.bat` 실행 후 다시 |
| `[SKIP] 네이버 로그인이 풀렸습니다` | 네이버가 로그아웃됐습니다 | 그 크롬 창에서 다시 로그인 |
| `[확인필요]` | 글이 두 번 올라갈 수 있는 상태 | 손대지 말고 지니에게 알려 주세요 |
| `[SKIP] 큐에 남은 글이 없습니다` | 10편을 다 썼습니다 | 지니에게 "글 더 채워줘" |
| `[보류] 사진 부족으로 보류` | 그 글의 사진이 2장 미만 | `py -3 prepare_images.py --prepare` 후 다시 |
| `임시저장 개수 …→… — 중복 생성 의심, 전부 중단` | 덮어쓰기가 새 글로 저장됨 | 손대지 말고 지니에게 알려 주세요(옛 글은 지우지 않음) |
| `[게이트] … 합격 기준 미달` | 재작성 글의 서식 검사 실패 | `logs/rework_*.png` 와 `format_verify_*.json` 확인 |
| `[SKIP] 전용 크롬에서 threads 로그인이 풀렸습니다` | 쓰레드 로그아웃 | 전용 크롬 창에서 threads.com 다시 로그인 |

로그는 `logs\` 폴더에 날짜별로 남습니다(`threads_날짜.log`, `naver_날짜.log`, 스크린샷).

## 멈추고 싶을 때

- **잠깐 멈춤**: `.env.local` 에 `SNS_DAILY_ENABLED=0` 한 줄을 넣습니다. (다시 하려면 `1`)
- **완전히 끄기**: `unregister_sns_schedule.bat` 실행.
- **비밀번호·토큰이 걱정될 때**: `.env.local` 파일을 지우면 자동 게시가 즉시 멈춥니다. Meta 화면에서 토큰도 폐기할 수 있습니다.
