# 연동 노트 — 쇼룸 등록 준비 (이번 회차 미등록)

**상태: 관문 G6(대표님 직접 시연) 미실시 → 쇼룸·`oneclick` 저장소 무변경, 대외 판매·광고 0건.**
아래는 대표님이 폰으로 눌러 보시고 "팔아도 된다"고 하신 뒤 한 번에 할 일입니다.

## 1. 옮길 것
- 이 폴더 전체(`index.html` 제외 가능)를 `oneclick` 저장소의 새 폴더(예: `commerce/`)로 복사.
- 경로는 모두 상대경로(`assets/...`)라 폴더째 옮기면 그대로 동작합니다.

## 2. 바꿀 파일·줄
| 대상 | 바꿀 것 |
|---|---|
| `oneclick` 쇼룸 목록 페이지 | `patch/showroom_cards.html`의 카드 5개를 목록에 붙여넣기 |
| 각 도구 `.banner` (5곳 + 허브) | `index.html#more` 링크를 쇼룸의 더 뷰·더양식·더상세 실제 주소로 |
| 각 도구 헤더 `← 쇼룸` | `index.html` → 쇼룸 첫 화면 주소 |
| `assets/freekey.js` | 무료 체험 열쇠를 쓸 경우에만(공개 저장소 주의 — 기존 oneclick 방식 그대로) |
| `assets/data/fees.json` · `duties.json` | `verified:false` 값(수수료·환율·관세율·배송요율)을 실제 값으로 → `src/build_data.ps1` 실행 |

## 3. 되돌리기
- 쇼룸에서는 카드 5개와 `commerce/` 폴더만 지우면 원상복구(다른 파일을 건드리지 않음).
- 이 저장소에서는 `git revert <이번 커밋>` 또는 폴더 삭제.
