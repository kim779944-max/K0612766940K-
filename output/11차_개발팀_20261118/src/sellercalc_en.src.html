Formula
Profit = Price − Referral (Price × %) − Fulfillment − Storage − Inbound − Product cost (in USD) − Per-item fee − Return allowance (Price × return %, assumes returned units are not resold).
Break-even price = fixed costs ÷ (1 − referral % − return %). Target price = fixed costs ÷ (1 − referral % − return % − target %).
