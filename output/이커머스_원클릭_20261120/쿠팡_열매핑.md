# 쿠팡 Wing 열 대응표 (우리 평면 표 → Wing 일괄등록 양식)

> Wing 공식 일괄등록 양식은 **판매자센터(Wing) → 상품관리 → 상품 일괄등록**에서 카테고리별로 내려받아야 합니다.
> `coupang.html`이 만드는 `쿠팡_Wing등록_*.xlsx / .csv`는 그 양식에 **붙여넣기 좋은 평면 표(15열 × 1행)**입니다.
> Wing 양식의 실제 열 이름·순서는 카테고리·양식 버전마다 다르므로, 아래 "Wing 쪽 이름"은 **대표 명칭**입니다(확인 2026-11-20, 로그인 필요 화면이라 원문 대조 미실시 — 다운로드한 양식 머리줄과 맞춰 주세요).

| # | 우리 열 | Wing 쪽 이름(대표) | 채우는 값 | 비고 |
|---|---|---|---|---|
| 1 | 노출상품명 | 노출상품명 | 상품명 A안(핵심앞배치형) | 100자 이내 |
| 2 | 등록상품명 | 등록상품명(판매자 관리용) | 입력한 상품명 | 손님에게 안 보임 |
| 3 | 브랜드 | 브랜드 | `브랜드없음` | 자체 브랜드가 있으면 바꾸기 |
| 4 | 카테고리코드 | 카테고리(코드) | 비움 | Wing 카테고리 검색으로 선택 |
| 5 | 판매가 | 판매가격 | ④ 마진표 권장가(또는 고른 가격) | 손익분기 아래 가격은 선택 불가 |
| 6 | 재고수량 | 재고수량 | 100 | |
| 7 | 배송방법 | 배송방법 | `택배` | |
| 8 | 배송비 | 배송비 / 배송비 종류 | 입력한 판매자 배송비 | 0이면 무료배송 |
| 9 | 상품상태 | 상품상태 | `새상품` | |
| 10 | 대표이미지 | 대표이미지 | 첫 사진 파일 이름 | Wing에는 이미지 파일·URL로 등록 |
| 11 | 상세설명 | 상세설명(이미지/HTML) | `상세_*.png 첨부` | ③ 탭의 PNG를 올리기 |
| 12 | 원산지 | 원산지 | `상세페이지 참조` | 실제 원산지로 바꾸기 권장 |
| 13 | 상품코드 | 판매자상품코드 | `KTS-yyyymmdd-번호` | |
| 14 | 옵션명 | 옵션명 | `단일상품` | |
| 15 | 중량 | 중량(g) | 규격에서 뽑은 g 숫자 | |

## 오픈 API(사업자용) 필드 대응
요청 본문은 `coupang.html` ⑤ 탭 (나)에서 `coupang_body.json`으로 받습니다. `sellerProductName`=노출상품명, `items[0].salePrice/originalPrice`=판매가, `items[0].searchTags`=태그 20개, `deliveryCharge`=배송비.
`displayCategoryCode`·`returnCenterCode`·`outboundShippingPlaceCode`는 Wing에서 확인한 값으로 바꿔야 실제 등록이 됩니다(지금은 자리표시자).
