## 2. #23 지출결의서 1초 정리 — `oneclick/expense.html`

### 화면 흐름(3단)
| 단계 | 화면 | 누르는 것 |
|---|---|---|
| 1 모으기 | [영수증 사진 넣기(여러 장)] · [직접 한 줄 추가]. 사진 1장 = 카드 1줄(사진 썸네일 + 일자·거래처·합계·부가세·용도·증빙종류) | 사진 넣기 → 카드 값 입력 |
| 2 고치기 | 카드 값을 바로 고침. 빨간 칸 = 빠진 값, 노란 띠 = 중복 의심(같은 날·같은 거래처·같은 금액), 검산 줄(공급가액+부가세=합계) | [부가세 자동(1/11)] · 삭제 |
| 3 내보내기 | 서식 3종(일반·출장·접대) 고르기 + 머리 정보 · 결의서 미리보기 | [엑셀(.xlsx)] · [인쇄 · PDF] · [사진 목록 인쇄 포함] |

### 필수 입력
- 줄마다: 일자, 거래처, 합계(부가세 포함 결제액), 용도, 증빙종류. 부가세는 0도 허용(간이영수증·면세).
- 머리: 작성자, 결의 제목. 출장: 출장지·기간·목적. 접대: 접대 상대·인원·목적.

### 계산·판정 규칙
| 항목 | 규칙 |
|---|---|
| 부가세 자동 | 증빙이 세금계산서·카드영수증·현금영수증이면 `부가세 = 합계 − round(합계 ÷ 1.1)` (= 합계의 1/11, 원 단위 반올림). 간이영수증은 0 |
| 공급가액 | `공급가액 = 합계 − 부가세` (엑셀에서도 수식 `=H행−G행`) |
| 검산 | 줄마다 `공급가액 + 부가세 = 합계` 확인, 전체는 `Σ공급가액 + Σ부가세 = Σ합계` 확인해 화면에 "검산 일치" 표시 |
| 부가세 이상 | 과세 증빙인데 부가세가 1/11 계산값과 ±10원 넘게 다르면 노란 표시 |
| 중복 의심 | 일자·거래처(공백 제거)·합계가 모두 같으면 두 줄 모두 "중복 의심" |
| 누락 | 필수 칸이 비면 빨간 테두리 + 단계 옆 개수 |

### 서식 3종(내장)
- 일반: 결의 제목 · 작성자 · 부서 · 작성일 · 결재란(담당/팀장/대표) · 지출 내역 표 · 합계.
- 출장: 일반 + 출장지 · 출장 기간 · 출장 목적. 용도 기본값 "교통비/숙박비/식대".
- 접대: 일반 + 접대 상대 · 인원 · 목적. 용도 기본값 "접대비".

### 엑셀(.xlsx)
- `converter.html` 엔진 `normalize → buildXlsx → makeZip`으로 시트를 만들고, 합계 줄과 공급가액 칸에 수식(`<f>`)을 넣는다(값도 함께 넣어 바로 보임).
- 열: 번호 · 일자 · 거래처 · 용도 · 증빙 · 공급가액 · 부가세 · 합계 · 사진. 숫자 칸 서식 `#,##0`.

## 3. #19 견적서 1초 발행 — `oneclick/quote.html`

### 화면 흐름(3단)
| 단계 | 화면 | 누르는 것 |
|---|---|---|
| 1 내 정보 | 상호 · 대표자 · 사업자등록번호 · 주소 · 전화 · (선택) 이메일·계좌 | [내 정보 저장] (1회, 이 기기) |
| 2 품목 | 고객명 · 견적일 · 품목 행(품명·규격·수량·단가 → 금액 자동) · 부가세 별도/포함 · 유효기간(D+7/15/30) · 결제조건 · 비고 | [+ 품목] · [−] |
| 3 미리보기·발행 | A4 견적서 미리보기 · 발행 대장(최근 발행 목록) | [발행(번호 받기)] → [인쇄 · PDF] · [한글(.hwpx)] |

### 필수 입력
- 내 정보: 상호, 대표자, 연락처. 품목: 고객명, 품목 1개 이상(품명·수량·단가).

### 계산 규칙
| 항목 | 규칙 |
|---|---|
| 줄 금액 | 수량 × 단가 |
| 부가세 별도 | 공급가액 = Σ금액, 부가세 = floor(공급가액 × 0.1), 합계 = 공급가액 + 부가세 |
| 부가세 포함 | 합계 = Σ금액, 공급가액 = round(합계 ÷ 1.1), 부가세 = 합계 − 공급가액 |
| 한글 금액 | "일금 ○○○원정 (₩n)" — contract와 같은 한글 수 읽기 규칙 |
| 유효기간 | 견적일 + n일, "2026년 12월 18일까지" |

### 연번 규칙(같은 번호 중복 0)
- 형식 `YYYY-NNNN`(견적일의 연도, 4자리 0 채움). 대장은 `localStorage 'kq_ledger_v1'` 배열.
