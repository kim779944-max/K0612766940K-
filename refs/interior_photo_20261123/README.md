# 인테리어 실사 세트 (2026-11-23 · 지니 제작 · 대표님 승인 경로)

인테리어 도구(`oneclick/interior/`)가 **허접한 도면 대신 실사 사진**으로 비포/애프터를 보여 주기 위한 자산이다.
128번 지시서에서 "못 구하면 SVG 도면으로 시작하고, **나중에 지니가 실사 세트로 갈아끼운다**"고 정한 그 실사 세트다. 이제 도면은 폐기한다(150번).

## 1. 파일

| 파일 | 용도 | 규격 | 크기 |
|---|---|---|---|
| `ba_living.jpg` | 거실 — **1순위 대표 샘플** | 1200×900 (4:3) | 93KB |
| `ba_room.jpg` | 원룸(방) — 보조 탭 | 1200×900 | 108KB |
| `ba_shop.jpg` | 매장 — 보조 탭 | 1200×900 | 93KB |
| `living_setA.jpg` | 거실 가구 배치 **전** (소파 왼쪽) | 1200×900 | 129KB |
| `living_setB.jpg` | 거실 가구 배치 **후** (소파 오른쪽·식탁 왼쪽) | 1200×900 | 137KB |
| `mat_denbar.jpg` | 덴바보드(세로 골 판넬) 텍스처 | 800×800 | 47KB |
| `mat_marble.jpg` | 대리석 텍스처 | 800×800 | 53KB |
| `mat_floor.jpg` | 강마루 텍스처 | 800×800 | 109KB |
| `mat_wallpaper.jpg` | 도배 텍스처 | 800×800 | 99KB |
| `mat_tile.jpg` | 타일 텍스처 | 800×800 | 28KB |
| `regions.json` | 사진별 벽·바닥 영역 좌표 + 자재 목록 | — | — |

- 5장의 공간 사진은 **같은 카메라 높이·같은 원근**(눈높이 정면)으로 만들었고, `living_setA/B` 는 **바닥·벽·창·조명·카메라가 완전히 같고 가구만 다른** 한 쌍이다(같은 원본에서 파생).
- 자재 텍스처는 **정면·균일 조명·원근 왜곡 0** 이라 벽·바닥 영역에 그대로 매핑하면 사진처럼 붙는다.

## 2. 사용 규칙 (지시서 §에 그대로 있다)
1. `oneclick/interior/img/` 로 **원본 그대로 복사**한다(리사이즈·재압축 금지 — 이미 규격에 맞춰져 있다).
2. **고른 자재의 영역만** 바뀐다. `regions.json` 의 `wall`/`floor` 다각형 안에만 텍스처를 매핑하고, 나머지 픽셀은 원본 그대로 둔다.
3. 자재 하나가 부득이 다른 부위까지 바꾸면 `materials[].bundle` 에 적힌 항목을 **화면에 함께 표시**한다(예: "덴바보드 + 걸레받이 함께 변경").
4. `regions.json` 좌표는 사람이 눈으로 잰 **시작값**이다. 390 실측 캡처에서 경계가 어긋나면 **좌표만** 고쳐 맞춘다(사진을 자르거나 늘리지 않는다).
5. 예시 사진임을 숨기지 않는다 — 페이지 하단에 `예시 사진으로 보는 시공 전/후입니다. 실제 시공 결과와 다를 수 있습니다.` 1줄 고정.
